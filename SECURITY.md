# Security Policy

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability, please
report it privately instead of opening a public issue:

- **Preferred:** use GitHub Security Advisories — open the **Security** tab
  of this repository and choose **Report a vulnerability**.
- **Email:** [priyanshukumarthakur937@gmail.com](mailto:priyanshukumarthakur937@gmail.com)

Please include as much detail as you can: what the vulnerability is, where
it is, how to reproduce it, and the impact you believe it has. Do not include
real user data, credentials, or personal information in a report.

## Disclosure

- We will acknowledge your report and aim to provide an initial response
  promptly.
- We will investigate, confirm, and fix confirmed vulnerabilities.
- We ask that you give us a **90-day disclosure window** after we confirm the
  report before disclosing the vulnerability publicly, so a fix can be
  prepared and released.
- Please do not exploit the vulnerability beyond what is needed to
  demonstrate it, and do not access or modify other people's data.

## Scope

This policy covers the code and configuration in this repository, including
the application code, tests, and build/dependency configuration. It does not
cover third-party services, infrastructure outside this repository, or
social-engineering and physical-security reports.

Thank you for helping keep this project and its users safe.
